# Cómo administrar tu web

Web pública: https://brigitte-nunez-maldonado.github.io
Repositorio: https://github.com/brigitte-nunez-maldonado/brigitte-nunez-maldonado.github.io

## Cambiar textos, proyectos o formación
1. Entra en el repositorio (con tu sesión de GitHub abierta).
2. Abre el archivo **datos.js** y pulsa el lápiz ✏️ (Edit).
3. Cambia solo lo que está entre comillas "...". Mantén comas y llaves.
4. Pulsa **Commit changes** → **Commit changes**.
5. En 1–2 minutos la web se actualiza sola.

## Añadir o cambiar una foto
1. Entra en la carpeta **img** → **Add file** → **Upload files** → arrastra la foto → **Commit changes**.
2. En **datos.js**, escribe el nombre de la foto, por ejemplo `img/mi-foto.jpg`.
   - Cada proyecto admite 1 foto principal y hasta 2 adicionales.

## Ocultar un proyecto sin borrarlo
En **datos.js**, cambia `visible: true` por `visible: false`.

## Actualizar el CV
Entra en la carpeta **docs**, sube el nuevo PDF con el mismo nombre
`CV_Brigitte_Nunez_ES.pdf` y pulsa **Commit changes**.

## Si algo sale mal
En el repositorio, pestaña **Commits**: ahí está el historial y puedes ver o
recuperar cualquier versión anterior.
